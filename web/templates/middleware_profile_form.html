Security headers
Forward auth

Delegate authentication to an external service (Authentik, Authelia, …) before proxying. A 2xx answer lets the request through and copies the listed headers to the upstream; anything else is shown to the visitor. A host with its own forward auth URL keeps its own settings.

IP restrictions
Extra headers

JSON objects of header name to value. A header set on the host with the same name wins.

Web application firewall (Coraza)

Inspects requests with Coraza and the OWASP Core Rule Set (SQL injection, XSS, path traversal, scanners…) before they reach the upstream. Start with Detection only: it logs what it would block (visible under Server Logs) without blocking anything, so you can see false positives before switching to Block. Needs a Caddy built with the Coraza module — applegater/caddyui-caddy v2.61.0 or newer; CaddyUI checks this before saving.
