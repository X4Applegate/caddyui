REST API Reference

CaddyUI exposes a versioned REST API under /api/v1. All endpoints return JSON.

{{/* ── Authentication ── */}}

Authentication

All endpoints require authentication via either a session cookie or an Authorization: Bearer <token> header. API tokens can be created on the API Tokens page (sidebar → API Tokens).

Example — Bearer token header

Authorization: Bearer caddyui_tok_abc123…

Requests without a valid credential receive 401 Unauthorized.

POST /api/v1/proxy-hosts

Create a new proxy host. Returns the created object with its assigned id.

Request body

{
  "domains": "app.example.com",
  "forward_scheme": "http",
  "forward_host": "192.168.1.10",
  "forward_port": 3000,
  "ssl_enabled": true,
  "ssl_forced": false,
  "http2_support": true,
  "websocket_support": true,
  "enabled": true,
  "compression_enabled": false,
  "cors_enabled": false,
  "cors_origins": "*",
  "block_common_exploits": false,
  "security_headers_enabled": false,
  "certificate_id": 0,
  "tags": "",
  "notes": ""
}

Response — 201 Created

{ "id": 7, "domains": "app.example.com", … }
PUT /api/v1/proxy-hosts/{id}

Replace a proxy host's configuration. Send only the fields you wish to update; omitted fields retain their current values.

Request body

{
  "forward_host": "192.168.1.20",
  "forward_port": 8080
}

Response — 200 OK

{ "id": 7, "forward_host": "192.168.1.20", "forward_port": 8080, … }
DELETE /api/v1/proxy-hosts/{id}

Delete a proxy host. The corresponding Caddy route is removed immediately.

Response

204 No Content
POST /api/v1/proxy-hosts/{id}/toggle

Toggle a proxy host between enabled and disabled. The route is added to or removed from Caddy accordingly.

Response

{ "id": 7, "enabled": false, … }
POST /api/v1/proxy-hosts/{id}/maintenance

Toggle maintenance mode on a proxy host. When active, all requests to the domain receive a branded maintenance page instead of being proxied upstream.

Response

{ "id": 7, "maintenance_mode": true, … }
