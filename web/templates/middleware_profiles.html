Middleware profiles

Reusable bundles of HTTP policy — security headers, forward auth (for example Authentik or Authelia), IP restrictions and extra headers — configured once and picked on any number of proxy hosts. Editing a profile re-syncs every server that has a host using it. A value set on a host itself wins; empty host fields inherit the profile.
